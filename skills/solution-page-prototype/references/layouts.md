# 内容与布局设计指引

本指引用于从文字定稿到可审阅的页面原型。先保留本页内容，再寻找合适的构图，用布局帮助客户理解业务和关系。

## 一、先确定内容及其关系

阅读本页对应段落，带入主要结论、建设内容、使用过程、具体例子和重要条件。结合内容区分重点和辅助信息，给真实信息分配面积，不按固定区块数量拆文案。

把信息关系转为构图依据。例如，多种信息进入同一设备档案，可以用来源汇入共同对象的结构；规则配合场景再触发处理，可以让规则和场景相邻，处理过程接在下方；总览页同时包含态势、定位和业务去向，可以将概况、场景与去向组织为相连的区域。这些是关系的表达示例，不是页型模板。

同一页兼有能力说明与使用示例时，给两者安排位置。不能用一个简化例子代替整页能力，也不能只留功能名、删掉业务过程和影响成立的条件。

## 二、逐页定向寻找布局参考

主要参考 [PPTNest](https://www.pptnest.com/) 及其 [产品与界面布局分类](https://www.pptnest.com/slide-type/product-screenshot-slide-examples)，也可按页内关系查找流程、对照、框架或多图构图。

1. 按已经知道的页面内容发起检索，例如多来源汇入同一对象、图片局部标注加业务流程、上下概况与场景组合。根据文字量、图示复杂度和素材数量筛选，不以行业相同作为主要匹配条件。
2. 同组页面的相关检索合并进行，先比较缩略图或分类页，候选确实适合时再看大图。让参考覆盖各页实际需要的关系，不随机选几张构图代表整组，也不设固定数量配额。
3. 借鉴区域划分、面积比例、对齐、图文穿插和阅读路径，再用本页内容重新组织。参考的颜色、字体、图片和装饰不带入原型。
4. 已有参考能承载该页内容及关系时结束查找，组内适用的参考可复用。网站不可访问时，直接按以下构图动作完成设计，简短说明参考未能读取，不持续重试或转去搜学术论文。

## 三、将内容组织成视觉页面

### 建立主次和阅读路径

- 让最能解释本页内容的对象获得主要空间，它可以是场景、关系图、对照、业务过程或组合区域，不固定为一张大图。辅助信息靠近对应对象，避免统一堆到侧边。
- 用连续区域、明显的尺度差和间距形成层级。标题说明主题或结论，小标题说明业务用途，正文承载必要细节；不要把所有区块做成相同大小和权重。
- 按实际理解顺序安排视线。将输入、共同对象、处理动作与结果在空间上接续，让读者能顺着页面读出过程。并列内容对齐，递进内容沿路径展开；共用说明只在共同位置写一次。
- 用留白分隔不同关系，用紧邻关系连接属于同一对象的内容。框线用于圈定范围、阶段或对象，不给每段文字都加卡片；技术箭头只表示真实的流转、调用、交接或依赖。

### 组合文字、图示和素材

- 把步骤、流向、来源归集和对应关系转成图形，文字贴近相应节点；图形已说明的信息不再用长段落复述。规则、边界和关键条件仍保留可读的完整含义。
- 真实截图或场景图只突出与本页有关的部分。可裁切、局部放大、加定位标注，配合邻近的说明；不能为了大图效果把实际细节缩到无法辨认。多图承担不同作用时按重要性分配面积，确有对照需求时统一视角或比较维度。
- 无适用素材时，按最终图的用途和比例预留区域，标明需补充的真实素材。保留页面原有业务信息，不用巨大的空白图片区替代内容，也不虚构系统界面、数据或效果。
- 一页可以组合概况、场景、规则、来源、过程和结果，依据关系安排上下穿插、嵌入或汇聚等结构。避免把所有页面都做成大图加一侧三组文字，也不为形式变化强行增加区块。

### 处理密度和容量

先调整区域大小、图示表达和重复说明，再缩短措辞。保留能让客户理解功能如何使用、处理什么、得到什么结果的细节，不能把完整方案降成一组抽象关键词。

内容超量时，先重组关联内容、缩减冗余表达或不必要占位。确需移页时在页面规划写明去向；不能静默删除，也不能靠极小正文塞满。标题和小标题单独顺读，应能够传达本页的业务用途或关键结论。

## 四、可采用结构化默认组织的内容

| 内容 | 设计动作 |
| --- | --- |
| 总体架构 | 以架构图为主体，按实际关系组织角色入口、应用模块、共用服务和数据，标明关键连接。公司模板有指定架构版式时按其组织，正式制作落实公司视觉规范 |
| 建设路径 | 沿阶段安排建设工作和可见成果，突出每阶段形成什么；仅在有依据时加入时间和先后依赖 |
| 合作分工 | 按实际角色或交接环节组织，突出各方职责、交付物与接收关系 |

其他页面按实际内容自由构图，不按“场景页”“流程页”等名称锁定版式。平行对照的页面可以使用系列布局；相邻页内容关系不同，应相应调整空间组织。

## 五、组内出稿检查边界

随该组原型完成一次内容与构图检查：关键信息有落点，主次和阅读顺序清楚，图形没有改变事实，文字在实际展示尺寸可读。此阶段不检查公司色彩、字体规范或 PPT 原生对象；这些留给正式制作。修复后只复查受影响内容。
